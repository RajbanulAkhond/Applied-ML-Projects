# Fibres: Contrast-Enhanced Images

This folder contains **153 images** for the **Fibres** category in the [SEM image analysis project](../../README.md).

These copies increase image contrast by a factor of 2. I compare them with the original condition to examine how intensity transformations affect PCA and clustering.

I practiced contrast adjustment with Pillow and comparing the effects of image preprocessing on unsupervised analysis.

See the [image-data README](../README.md) for the source dataset, augmentation script, and full directory structure. The project notebook uses the image files in this folder; this README is ignored by its image loader.
