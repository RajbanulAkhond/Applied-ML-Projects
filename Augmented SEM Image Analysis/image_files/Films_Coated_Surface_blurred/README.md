# Films and Coated Surfaces: Blurred Images

This folder contains **308 images** for the **Films and Coated Surfaces** category in the [SEM image analysis project](../../README.md).

These copies apply Gaussian blur with radius 15 to the corresponding source images. I compare them with the original condition to examine how smoothing changes explained variance and clustering.

I practiced applying Gaussian filters with Pillow and assessing how loss of image detail changes a machine-learning representation.

See the [image-data README](../README.md) for the source dataset, augmentation script, and full directory structure. The project notebook uses the image files in this folder; this README is ignored by its image loader.
